# Kitchen Renovation Mumbai Landing Page

## Run locally

1. Install Node.js 20+.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000

## Replace before launch

In `app/page.tsx`:
- `YOUR BUSINESS NAME`
- `WHATSAPP_NUMBER`
- `PHONE_NUMBER`
- Project image paths
- Actual service areas

## Project photos

## Lead form

The demo form currently points to the WhatsApp link. For production, connect the form to a real lead destination such as a form endpoint, CRM, Google Sheet automation, or your own API.
